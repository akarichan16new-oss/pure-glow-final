# PureGlow AI 🌸

PureGlow AI is a skincare and makeup recommendation web application.  
It helps users receive personalised skincare and makeup suggestions based on their skin profile, preferences, and beauty needs.

This project includes a React frontend, Python backend, recommendation logic, notebooks, reports, and machine learning support files.

---

## ✨ Features

- Skin quiz for collecting user preferences
- Skincare and makeup product recommendations
- Product cards with category, price, rating, and relevance score
- Personalised result page
- “Why this?” explanation feature
- Pink and white themed user interface
- Responsive frontend design
- Backend recommendation system
- Machine learning/data analysis workflow
- Dataset and model files excluded from GitHub due to size limits
